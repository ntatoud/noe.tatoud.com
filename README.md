# noe.tatoud.com

Personal website and blog of Noé Tatoud, built with TanStack Start, React 19,
Tailwind CSS 4 and an Effect-based content pipeline.

## Develop

```sh
pnpm install
pnpm run dev        # http://localhost:3000
pnpm run check      # format check + lint
pnpm run typecheck
pnpm test
pnpm run build
```

See `CLAUDE.md` for the architecture, `CONTEXT.md` for the domain vocabulary
and `docs/adr/` for the decisions behind it.
