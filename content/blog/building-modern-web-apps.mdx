# Building Modern Web Apps with TanStack and Fumadocs

The JavaScript ecosystem has evolved significantly over the past few years. Today, we have access to powerful tools that make building type-safe, performant web applications more accessible than ever.

## The Stack

This blog is built using a combination of modern tools:

- **TanStack Start** - A full-stack React framework with file-based routing
- **Fumadocs MDX** - A content processing layer for handling MDX files
- **Tailwind CSS v4** - Utility-first CSS with the new oxide engine
- **Bun** - A fast JavaScript runtime and package manager

## Why TanStack Start?

TanStack Start offers several advantages over traditional React frameworks:

1. **Type-safe routing** - Routes are fully typed, catching errors at compile time
2. **Server functions** - First-class support for server-side logic with `createServerFn`
3. **Flexible deployment** - Deploy anywhere with Nitro adapters

## Content with Fumadocs

Fumadocs MDX transforms your content into type-safe data. Define your collections in `source.config.ts`:

```ts
import { defineCollections, frontmatterSchema } from 'fumadocs-mdx/config'
import { z } from 'zod'

export const blogPosts = defineCollections({
  type: 'doc',
  dir: 'content/blog',
  schema: frontmatterSchema.extend({
    author: z.string(),
    date: z.string().date().or(z.date()),
  }),
})
```

This gives you full type safety for your frontmatter and content.
