## What is Start UI?

Start UI [web] is an opinionated starter kit for building full-stack TypeScript apps. It bundles TanStack Start, Tailwind CSS, shadcn/ui, oRPC, Prisma, and Better Auth into a single, cohesive foundation, so you can skip the boilerplate and start building features from day one.

With **~1,700 stars on GitHub**, it's used by the BearStudio team on every internal project and adopted by developers outside the team as well.

[start-ui.com](https://start-ui.com)

[Documentation](https://docs.web.start-ui.com)

## What makes it different

There are countless starters out there. What sets Start UI apart is discipline:

- **No feature creep.** We don't try to do everything. No 25 CLI flags to pick your perfect setup, just one solid, proven stack.
- **Close to real production needs.** Every choice in Start UI comes from shipping real apps. If we don't use it in production, it doesn't make it in.
- **A living reference for best practices.** Beyond scaffolding, Start UI is meant to be a good example of how to structure a project, organize code, and use the tools we rely on every day.

Yoann Fleury wrote a great introduction to the project's philosophy on the BearStudio blog:

[Start UI — one great opinionated UI starter](https://www.bearstudio.fr/blog/actualites-web-numerique/start-ui)
